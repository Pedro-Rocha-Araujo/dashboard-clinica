# 🩺 Dashboard Clínica 

## 🗒️ Descrição do projeto:
* O presente projeto é um sistema de gerenciamento de senhas e chamados desenvolvido para uma clínica

<img width="1920" height="911" alt="miniatura-dashboard" src="https://github.com/user-attachments/assets/6915200b-3aaa-4367-9862-d82c15b9883c" />

### 🔧 Tecnologias usadas para o desenvolvimento:
* Typescript
* React.js | Next.js
* Node.js | Express
* MongoDb | Mongoose

### 📐 Características do projeto: 
* Backend desenvolvido com arquitetura MVC
* Criptografia de senha
* Verificação de usuário via Token JWT
* Interface 100% responsiva com abordagem Mobile-first

### ⚙️ Funcionalidades: 
* Cadastro e login para usuários e profissionais
* Cadastrar e gerenciar novos profissionais e especialidades
* Cadastrar senhas para os pacientes
* Automaticamente as senhas do dia anterior são encerradas dinamicamente e se inicia uma nova contagem
* Encerrar ou Finalizar o atendimento
* Tela de listagem de senhas por profissional
